# Engineering Certification Enablement Guide (Synthetic)

## AZ-900: Azure Fundamentals
Target roles: Cloud Engineer, IT Admin, Developer
Required skills: Cloud Concepts, Azure Services, Security, Pricing
Recommended study hours: 15
Pass threshold: 70%

### Study Tips
- Start with Microsoft Learn free AZ-900 path
- Focus on cloud concepts and Azure core services
- Practice with free sandbox environments
- Take at least 2 practice tests before exam

### Key Topics
1. Cloud computing concepts (IaaS, PaaS, SaaS)
2. Core Azure services (Compute, Storage, Networking)
3. Security and compliance
4. Azure pricing and support
